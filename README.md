# 🌡️ Temperature Converter (Micro Project 3E)

A simple, responsive temperature converter built with **HTML, CSS, and JavaScript**. It converts between **Celsius and Fahrenheit**.

[Live Demo](#) · [Report Bug](#) · [Request Feature](#)

---

## 📌 Overview

Enter a temperature, choose the conversion direction, and get the result instantly.

## ✨ Features

- Celsius → Fahrenheit conversion
- Fahrenheit → Celsius conversion
- Instant result on button click
- Input validation (empty or non-numeric values)
- Clean, responsive UI
- No dependencies

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| HTML5 | Page structure and form elements |
| CSS3 | Styling and responsive layout |
| JavaScript (ES6) | Conversion logic and DOM handling |

## 🧮 Conversion Formulas

| Conversion | Formula |
|---|---|
| °C → °F | `(C × 9/5) + 32` |
| °F → °C | `(F − 32) × 5/9` |

## 🚀 Getting Started

1. Clone the repo
   ```bash
   git clone https://github.com/[your-username]/temperature-converter.git
   ```
2. Open the folder
   ```bash
   cd temperature-converter
   ```
3. Open `TEMP_CONVERT.html` in your browser. No build step needed.
